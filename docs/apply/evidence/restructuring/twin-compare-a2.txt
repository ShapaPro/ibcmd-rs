Both twins were restored from the same backup of the staged image (bak/ibcmd_rs_04_ddl_bsp8327_a_a2_staged.bak: a native
`import files --partial` of the edited catalog, 9842 ConfigSave rows, nothing applied):
  native: ibcmd_rs_04_ddl_a2_nat  -- native `ibcmd infobase config apply --force --dynamic=disable` (8.3.27.2214)

Both then went through the same sessions/exports below. Machine: SQL Server 2025 on the same host, other tracks running.
